# Dubora

Dubora est une application mobile de doublage vidéo pensée pour Android et iOS.

## Objectif

Dubora vise à proposer un studio de doublage directement sur mobile, avec une interface pensée en priorité pour le paysage pendant le doublage et disponible en portrait.

## Fonctionnalités actuelles

- Importation de vidéos
- Prévisualisation vidéo
- Enregistrement vocal
- Affichage et édition de la phrase à lire
- Mode paysage privilégié pour le doublage
- Mode portrait disponible
- Bascule manuelle entre paysage et portrait
- Personnalisation de la taille du texte
- Personnalisation de l'épaisseur et du style
- Alignement du texte
- Couleur du texte
- Couleur et opacité du fond
- Nombre maximal de lignes
- Ombre du texte

## Fonctionnalités prévues

- Timeline de doublage
- Gestion des prises
- Réglage indépendant des volumes
- Synchronisation précise audio et vidéo
- Plusieurs pistes vocales
- Sauvegarde locale des projets
- Réduction du bruit
- Effets audio
- Sous-titres avancés
- Export vidéo avec doublage
- Outils de doublage assisté

## Version actuelle

0.1.0

## Plateformes

- Android
- iOS

## Builds

Les workflows GitHub Actions préparent des artefacts Android et iOS.

L'APK Android de développement est signé avec la clé de debug Android.

L'IPA iOS produit par le workflow de développement est non signé et destiné aux étapes de développement et de préparation. Une signature Apple sera nécessaire avant installation sur un appareil selon le mode de distribution utilisé.

## Développement

Le projet utilise Expo et React Native.
